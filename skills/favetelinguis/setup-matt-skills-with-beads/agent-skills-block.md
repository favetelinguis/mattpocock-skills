## Agent skills

### Issue tracker

Issues live in beads_rust (`br`) in every repo where `br where` finds a `.beads/` workspace; in a repo without one, tell the user to run `/setup-matt-skills-with-beads`. Read `~/.agents/skills/setup-matt-skills-with-beads/issue-tracker-beads.md` before any issue operation, and whenever you find work outside the current issue or produce an artifact for one.
